# Contributing to HashDup CLI 🤝

Thank you for your interest in contributing to **HashDup CLI**! We welcome all contributions: bug reports, performance enhancements, and pull requests.

---

## 🛠️ Local Development Setup

1. **Fork and Clone:**
   ```bash
   git clone https://github.com/mahdyarmonfared/hashdup-cli.git
   cd hashdup-cli
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Run the Test Suite:**
   ```bash
   npm test
   ```

---

## 🚀 Submitting Changes

1. **Create a Feature Branch:**
   ```bash
   git checkout -b feat/your-feature-name
   ```

2. **Ensure Tests Pass:**
   Always run `npm test` before pushing to verify hashing and scan integrity.

3. **Open a Pull Request:**
   Submit your PR to the `main` branch.

Happy coding! 🎉
